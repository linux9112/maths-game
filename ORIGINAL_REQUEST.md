## Requirements

### R1. Multiplication Table Mastery & Practice System
- Support table presets (1–10, 1–20, 1–30, 1–43, 1–50, 1–100), arbitrary custom ranges (e.g. 1–43), and multi-select individual tables (e.g. 7, 11, 17, 23, 43).
- Configurable multiplier ranges (×1–×10, ×1–×12, ×1–×20, and custom ranges).
- Table Learn Mode showing ordered table facts with an optional review timer (10s, 20s, 30s, 60s, or manual start).
- Mode A (Options): Multiple-choice with 4 choices generated by an intelligent distractor algorithm (no obvious last-digit or magnitude giveaways; distractors derived from neighboring tables, adjacent multipliers, and common calculation mistakes across Easy, Normal, Hard, and Expert difficulties; randomized option order).
- Mode B (Direct Typing): User types answers directly. Incorrect inputs do NOT advance the question; instead, subtle feedback is shown, requiring the user to type the correct answer before automatically clearing, advancing, and refocusing.
- Mobile keyboard visibility: Layout and viewport handling ensure virtual keyboards never obscure the active question, input field, or feedback.
- Mistake & Weakness tracking: Records attempts, accuracy, response times, and consecutive correct answers per calculation to maintain a weak-calculation list and compute table mastery percentages.

### R2. Operations & Multi-Level Arithmetic Engine
- Dynamic question generation engine for Addition (Levels 1–5: single-digit to 4-digit), Subtraction (Levels 1–4: non-negative beginner default up to 4-digit regrouping), Multiplication (Levels 1–5: single-digit to multi-digit), and Division (Levels 1–5: exact integer division default, progressing to remainders/larger numbers).
- Flexible operation selector supporting single operation (+, −, ×, ÷), arbitrary combinations, and an All Mixed mode.
- Shared distractor generation pipeline adhering to strict plausibility standards (e.g., for 11 × 9 = 99, never generate distractors that make 99 trivially identifiable by last digit).

### R3. Gamified Practice Suite
- Provide a dedicated games section organized with clean progressive disclosure categories (Speed, Survival, Memory, Battles, Challenges).
- Games: Rain Calculation (falling math problems, speed escalation, lives/combo), Survival (3 lives, combos), 60-Second Rush, Number Target (static/moving choices), Table Breaker (break number blocks), Table Battle (comparing 2+ tables), Table Chain (number sequences), Rocket, Calculation Runner, Bomb Defusal (countdown), Boss Battle (HP bar and combat mechanics), Quick Compare, Bigger or Smaller, Find the Mistake, Closest Answer, Memory Calculation, Operation Switch.
- Standardized game settings pre-flight: Operation selector, difficulty (Beginner to Expert/Extreme), question target (10, 25, 50, 100, Endless), time limits, and mistake limits.
- Stress-free Practice Mode: No timers, unlimited retries, optional hints.

### R4. Progression, Adaptive System & Offline Storage
- Adaptive Endless mode prioritizing the user's weakest calculations and tables mixed intelligently with normal questions.
- Daily Challenge seeded deterministically by date so it is consistent for all attempts on that day.
- Progression system: XP, Leveling (e.g., Mental Math Explorer), Streaks (current & best), and session combo tracking.
- Progress Dashboard: Daily question count, accuracy percentage, average response time, table mastery bars, operation breakdowns, weak calculation list, and a one-click Practice My Weakness mode.
- Complete offline capability via LocalStorage/IndexedDB state persistence, PWA manifest, and service worker.
- Polished, responsive UI with light/dark theme toggle, reduced-motion support, desktop keyboard controls (Enter to submit, Escape to exit), and optional synthesized/Web Audio sound effects with toggle.

## Acceptance Criteria

### Mathematical Correctness & Distractor Quality
- [ ] Table questions for any custom range (e.g. 1–43 with multiplier range 1–20) generate mathematically correct answers.
- [ ] Multiple-choice distractor algorithm passes validation: for any calculation (such as 11 × 9 = 99 or 43 × 7 = 301), distractors are unique, plausible, never duplicate the correct answer, and never leave the correct answer as the only choice with the correct last digit.
- [ ] Division generation in standard practice strictly produces exact integer division with no fractional or decimal results.

### User Interaction & Keyboard Behavior
- [ ] In Direct Typing mode, an incorrect answer keeps the user on the same question without advancing; entering the correct answer advances immediately and automatically focuses the input.
- [ ] Desktop keyboard navigation allows seamless operation via number keys, Enter to submit, and Escape to pause/exit without requiring pointer clicks between questions.
- [ ] On mobile viewports, the active calculation and input remain fully visible in the visual viewport above virtual keyboards.

### Architecture & Persistence
- [ ] Client-side state persists to LocalStorage/IndexedDB: table mastery, weak questions, XP, streaks, and settings survive page reload and browser restarts.
- [ ] Daily challenge produces identical question sets when generated with the same calendar date seed.
- [ ] Application registers a PWA manifest and Service Worker, functioning entirely offline without network connectivity.

### Automated Testing
- [ ] Test suite (Vitest + React Testing Library) executes and passes, covering the Question Generation Engine, Distractor Generator (verifying non-trivial distractor distributions), Division integer constraints, Table Mastery calculation, and Weakness tracking logic.
